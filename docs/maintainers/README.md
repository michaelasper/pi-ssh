# Maintainer docs

These three guides are for people who change or release pi-ssh. User docs live one level up.

- [Development](development.md) covers the check suite, the real-SSH harness, benchmarks, and packaging checks.
- [Releasing](releasing.md) covers version staging through GitHub Actions OIDC, npm approval, and the pi.dev catalog.
- [Verification](verification.md) records what actually ran for each release, with coverage limits stated next to the results.
